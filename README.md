# Charliejhorn Tap

## How do I install these formulae?

`brew install charliejhorn/tap/<formula>`

Or `brew tap charliejhorn/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "charliejhorn/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
